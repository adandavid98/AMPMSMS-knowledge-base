# Formatting Rules

- Do NOT use markdown asterisks (`**` or `*`) for titles, headers, bullet points, or bold text.
- Use Unicode bold characters (such as 𝗔-𝗭, 𝗮-𝘇, 𝟬-𝟵 or 𝐀-𝐙, 𝐚-𝐳, 𝟎-𝟗) for bold text and titles so that copied text remains clean and bold without asterisks in plain text editors.
- Use standard hyphens (`-`) or numbered lists (`1.`, `2.`) instead of asterisks (`*`) for list items.
